Ice Island Records in the CI2D3 Database

Interact with the database by:
  • filtering observations by attributes using selection options,
  • retrieve all database information* for a given observation by clicking an ice island polygon, or
  • visualising an ice island's lineage (i.e., ancestors and descendants) by clicking a polygon and selecting “Track Lineage”.

*see CI2D3 Database documentation for details on these fields

Filter Ice Island Observations

To apply multiple filters, click “Apply Filter” for first selection, then change selection and click “Additional Filter.”

Filter layering example: Calvingloc = PG + Calvingyr = 2010 + Area > 100
